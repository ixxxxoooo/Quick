## 架构特性
- Feature Module 之间 **零依赖**，仅通过 EventBus 通信
- AppCore **纯组装器**，不持有业务逻辑
- Swift 6+ strict concurrency
- macOS 26 Tahoe，SwiftUI + AppKit 桥接
- SPM 本地 Package 编译隔离
- 全局快捷键 ⌥Space 唤醒面板
